# _anh/ — chỗ quăng ảnh tạm

Quăng ảnh vào đây (tên gì cũng được), rồi chạy:

```bash
npm run anh <slug-bài>
```

Lệnh đó sẽ: đổi tên cho sạch → xếp vào `public/media/<năm>/<slug>/` → đo kích
thước → cảnh báo ảnh nặng → in sẵn dòng Markdown để dán vào bài.

Thư mục này nằm trong `.gitignore`, nên ảnh chưa dùng không lọt lên git.
